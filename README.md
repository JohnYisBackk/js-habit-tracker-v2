# Habit Tracker V2

A modern and responsive habit tracking application built with **HTML**, **CSS**, and **JavaScript**.

Track your daily habits, monitor your consistency, and stay motivated with a clean and intuitive interface.

---

## 🔗 Live Demo

👉 **Live Demo:** https://johnyisbackk.github.io/js-habit-tracker-v2/

---


## 🚀 Features

* Add and delete habits
* Mark habits as completed
* Daily progress tracking
* Habit streak system
* Local Storage support
* Responsive design
* Modern glassmorphism UI
* Progress statistics
* Clean and user-friendly interface

---

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

---

## 📊 Features Overview

* Create custom habits
* Track completed habits
* View your daily progress
* Save data automatically
* Responsive layout for desktop and mobile devices
